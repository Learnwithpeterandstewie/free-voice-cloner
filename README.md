## ✨ Features

- 🆓 **100% Free** - Runs on Google Colab's free T4 GPU (15GB VRAM)
- 🎼 **Professional Quality** - Generate music with lyrics, style control, and genres
- ⚡ **Fast Generation** - 5-7 minutes per minute of audio (BF16 optimized)
- 🎚️ **Advanced Controls** - Temperature, Top-K, CFG Scale parameters
- 🌍 **Multilingual** - Support for multiple languages
- 🎹 **Style Tags** - Piano, rock, jazz, electronic, acoustic, and more
- 💾 **No Setup** - Works directly in browser

---

## 📖 How to Use

1. **Click the "Open in Colab" badge** above
2. **Run Cell 1** - Install dependencies (~3-5 min)
3. **Run Cell 2** - Download AI models (~5-10 min, one-time only)
4. **Run Cell 3** - Generate your first song!

### Basic Steps:
- Enter your lyrics (or use the example provided)
- Choose style tags: `piano, calm, acoustic` (comma-separated)
- Set duration (30-360 seconds)
- Click **Generate Music** and wait for results

## 🔧 Advanced Parameters

| Parameter | Range | Effect |
|-----------|-------|--------|
| **Temperature** | 0.7 - 1.3 | Higher = more creative |
| **Top-K** | 20 - 100 | Controls diversity (50 = balanced) |
| **CFG Scale** | 1.0 - 3.0 | Style adherence (1.5-2.0 recommended) |

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| **CUDA Out of Memory** | Reduce duration or restart runtime |
| **Model Download Fails** | Check internet & retry (HF rate limits) |
| **Poor Audio Quality** | Improve lyrics, adjust temp to 0.9, CFG to 1.8 |
| **Session Timeout** | Upgrade to [Colab Pro](https://colab.research.google.com/signup) |
